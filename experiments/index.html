Experiments

Every article on this blog gets a small generative piece instead of a stock photo. Each one draws its subject: a CI job moving through its stages, reads hitting or missing cache lines, an agent calling its tools. They are plain canvas and JavaScript, they only animate while on screen, and they hold still if you prefer reduced motion.

  • fig. sphere

    Homepage

    Orbit

    A sphere lit from the upper left, shaded with an ordered (Bayer) dither so the light falls off in dots rather than gradients. Two tilted orbits pass behind it.

  • fig. pipeline

    DevOps · CI

    Pipeline

    One job moving through its stages. A stage lights up while it runs and keeps an ok once it has passed; the log line counts the wall-clock time.

  • fig. memory

    Performance · C#

    Memory access

    The same number of reads, in order on top and at random below. Sequential reads stay inside cache lines that are already loaded; random reads keep missing.

  • fig. cube

    C++

    Wireframe

    A cube in perspective projection over a dot lattice. Twelve edges, eight vertices, and the vanishing lines it sits on.

  • fig. graph

    Agents · Conan · CMake

    Graph

    A hub with its dependencies or tools. Messages travel along the edges; for agents that is a tool call, for a package manager a resolved requirement.

  • fig. mesh

    3D · glTF

    Mesh

    A rotating torus as a quad wireframe, with depth carried by brightness: what every converted model is underneath its materials.

  • fig. flow

    Linux · Docker · Git

    Packets

    Data moving between two endpoints on parallel lanes, at different rates and in both directions.

  • fig. field

    Everything else

    Noise field

    Interfering sine waves, dithered into characters. The fallback for posts without a more specific subject.
